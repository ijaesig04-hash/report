## ③ 테이스트 Taste — 감각 좋은 실제 웹사이트 수준으로 만들기
- 하는 일: 뻔한 AI 디자인이 아니라 실제 잘 만든 회사 웹사이트 수준(사진 크게, 한 화면에 한 구역, 절제된 움직임)으로 만들고, 브라우저로 직접 열어 점검까지 함
- 설치 (새 프로젝트 폴더에서):
  ```
  npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
  ```
- 고급 쇼핑몰 느낌이 필요하면 추가로 (예전엔 같은 저장소였는데 지금은 따로 옮겨짐):
  ```
  npx skills add https://github.com/Leonxlnx/taste-skill-classics --skill "high-end-visual-design"
  ```
- 이렇게 시키세요:
  `design-taste-frontend 스킬 써서 우리 쇼핑몰 브랜드 소개 페이지 만들어줘. 뻔한 중앙 정렬 히어로 말고, 매거진처럼 사진이 크게 들어가는 비대칭 레이아웃으로.`
- 조절 다이얼 3개 (스킬 파일 맨 위, 1~10): `DESIGN_VARIANCE`(레이아웃 실험 정도) · `MOTION_INTENSITY`(움직임 양) · `VISUAL_DENSITY`(정보 밀도)

## ① 어썸 디자인 Awesome Design — 유명 브랜드 디자인 규칙 참고
- 하는 일: 애플·노션·스트라이프 등 유명 브랜드의 디자인 규칙(색·글꼴·여백·버튼)을 `DESIGN.md` 한 장으로 정리한 모음. 설치할 것 없음
- 쓰는 법: 원하는 브랜드의 `DESIGN.md`를 받아 새 프로젝트 폴더에 넣기
  - 목록: https://github.com/voltagent/awesome-design-md/tree/main/design-md (브랜드별 폴더)
  - 예) 애플: `https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md/apple/DESIGN.md`
  - Claude에게 "awesome-design-md에서 ○○ 브랜드 DESIGN.md 받아서 프로젝트에 넣어줘"라고 해도 됨
- 이렇게 시키세요:
  `프로젝트 폴더에 있는 DESIGN.md 읽고, 그 색상·폰트·여백·버튼 규칙대로 우리 의류 쇼핑몰 가을 신상 랜딩페이지 만들어줘. 브랜드 로고나 이름은 쓰지 말고 디자인 규칙만 참고해.`
- 추천: 미니멀 = 애플, 스포티 = 나이키, 깔끔한 정보형 = 스트라이프·노션
- **디자인 규칙(톤·여백·폰트 크기)만 빌려오고, 로고·브랜드명·고유 그래픽은 쓰지 않기**
