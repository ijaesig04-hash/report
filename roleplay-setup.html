🎧 AI 응대 연습 · 처음 1번 설정

AI 고객 역할을 해 줄 Claude와 점수 기록용 작은 프로그램을 연결하는 과정이에요. 한 번만 하면 끝나요. 크롬 ⋮ → 데스크톱 사이트를 켜면 화면이 편해요.

⭐ 이미 설정을 마친 분 — 마지막 1번만 업데이트

아래 ② 프로그램 코드 복사 → Apps Script 기존 프로젝트에 전부 지우고 붙여넣기 → 저장 💾 → 배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포.

이번 코드는 자동 업데이트판이에요. 이후로는 기능을 고쳐도 다시 붙여넣거나 배포할 필요 없이 5분 안에 저절로 반영돼요. 키·비밀번호(스크립트 속성)는 그대로 두면 돼요.

  1. ① Claude API 키 만들기 콘솔에 로그인 → Create Key로 키를 만들고 복사해 두세요. (sk-ant-… 로 시작) 사용한 만큼만 내는 방식이라 Plans & Billing에서 소액(예: 5달러) 충전이 필요해요. 이 연습은 한 번에 몇 원 수준이에요.
  2. 불러오는 중…
  3. ③ Apps Script 새 프로젝트 열기 기존 내용을 모두 지우고 복사한 코드를 붙여넣은 뒤 저장(💾)하세요.
  4. 왼쪽 ⚙️ 프로젝트 설정 → 맨 아래 스크립트 속성 → 속성 추가로 2개를 넣고 저장해요.
    • 속성 ANTHROPIC_KEY = ①에서 복사한 키
    • 속성 ADMIN_PIN = 파트장 현황 볼 때 쓸 비밀번호 (숫자 4~6자리)
  5. 오른쪽 위 배포 → 새 배포 → 유형 ⚙️ → 웹 앱
    • 실행: 나 / 액세스: 모든 사용자 → 배포
    • 구글 권한 요청이 나오면 허용 (고급 → 안전하지 않음으로 이동 → 허용)
  6. 나온 웹 앱 URL(…/exec)을 복사해서 Claude 대화방에 붙여넣어 주세요. 제가 앱에 연결해 드려요.

키는 Apps Script 안에만 있고 앱 화면에는 나오지 않아요. 연습 기록은 내 구글 드라이브에 「AI 응대 연습 기록」 시트로 자동 생성돼요.
